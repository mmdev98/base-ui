# About Base UI Plus

<Subtitle>Every Base UI component, plus unstyled components built the same way.</Subtitle>

Base UI Plus is a library of headless React primitives in two layers:

- **Base UI, re-exported.** Every [Base UI](https://base-ui.com) entry point is available under the same path: `@base-ui/react/dialog` becomes `@mmdev98/base-ui-plus/dialog`. The package pins one exact Base UI release, so your app has a single copy.
- **More components.** Components Base UI doesn't have, such as [Clipboard](/react/components/clipboard) and [Gallery](/react/components/gallery), written with Base UI's tools and following its API: a `render` prop, `data-*` state attributes, and `value` / `defaultValue` / `onValueChange`.

Base UI Plus is not affiliated with MUI or the Base UI team.

## Features

### Headless

The components are unstyled, don't bundle CSS, and don't prescribe a styling solution.
Style them with Tailwind, CSS Modules, plain CSS or any other engine, using their `data-*` attributes.

### Accessible

Roles, ARIA attributes, focus and keyboard handling are part of every component, following the [WAI-ARIA design patterns](https://www.w3.org/WAI/ARIA/apg/patterns/).

### Composable

Every part renders one element, which you can replace or wrap through its `render` prop.

## Built on Base UI

Base UI is made by the team behind Radix, Material UI and Floating UI at MUI. Most of this documentation is Base UI's own, adapted to the package's import paths. See [Base UI's about page](https://base-ui.com/react/overview/about) for its team and goals.

## Browser and React support

The re-exported components support what Base UI supports: all modern browsers that implement features marked as [Baseline Widely Available](https://web.dev/baseline). The package requires React 19.

## Community

Visit the [Community](/react/overview/community) page to learn where to get help and how to contribute.
