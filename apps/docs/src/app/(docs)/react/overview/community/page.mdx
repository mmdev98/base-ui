## The Base UI ecosystem

Base UI Plus re-exports Base UI, so the projects built around Base UI work with it too.

### shadcn/ui

[shadcn/ui](https://ui.shadcn.com/) uses Base UI as its unstyled foundation. If you want Tailwind-styled wrapper components and higher-level APIs without building that layer yourself, you can create a component library with the shadcn/ui [create](https://ui.shadcn.com/create) tool.

### Styled libraries

Here's a non-exhaustive list of open-source styled libraries built with Base UI:

- [Kumo](https://kumo-ui.com): Cloudflare's component library for building modern web applications.
- [coss ui](https://coss.com/ui): a modern UI component library. Built by the people behind [cal.com](https://cal.com).
- [Fragments](https://www.usefragments.com): a design system platform that includes a component library built on Base UI.
- [Lumi UI](https://www.lumiui.dev): composable React components.
- [Olyx UI](https://www.olyxui.com): composable components styled with native CSS and HCT color system.
- [ReUI](https://reui.io): a large collection of components and templates built on shadcn/ui.
- [FigUI](https://figui.dev): a Figma UI3 style component library for building Figma plugins.

### Unofficial ports

- [base-ui-solid](https://github.com/msviderok/base-ui-solid): unofficial port of Base UI to SolidJS.
- [base-ui-vue](https://github.com/vuepont/base-ui-vue): unofficial port of Base UI to Vue.
- [radix-ng](https://github.com/radix-ng/primitives): unofficial Angular adaptation of Base UI architecture and behavior (originally a Radix UI port).

## Get help and contribute

### Base UI Plus

To report a bug in a Base UI Plus component (Clipboard, Gallery …) or in the package, open an issue on [GitHub](https://github.com/mmdev98/base-ui-plus).

### Base UI

Bugs in a re-exported component usually belong to Base UI. Check that it happens with `@base-ui/react` too, then report it on [Base UI's GitHub](https://github.com/mui/base-ui). Base UI's community also runs a [Discord](https://base-ui.com/r/discord).

## Stay up to date

Base UI's own [releases](/react/overview/releases) are listed in these docs. A Base UI change reaches your app when you update `@mmdev98/base-ui-plus`.
