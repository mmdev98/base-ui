## API Reference

### Root

Holds the gallery state: the items, the active index, the viewer's open
state and animation, and the zoom of the active image. Place triggers,
lists and the viewer parts anywhere inside it. Renders no element.

**Root Props:**

| open          | `boolean`                                                            | -                  | Whether the viewer is open.                                                                                                                                                                                |
| onOpenChange  | `((open: boolean) => void)`                                          | -                  | Called when the viewer opens or closes.                                                                                                                                                                    |

### Trigger

Opens the viewer on one item. The image flies from the trigger to the
viewer and back. Put the thumbnail inside it. When `index` has no item,
only the children render, without the button. Inside `Gallery.List`, a
trigger past the list's limit renders nothing.
Renders a `<button>` element.

**Trigger Props:**

| Prop    | Type     | Default | Description                 |
| :------ | :------- | :------ | :-------------------------- |
| index\* | `number` | -       | Index of the item it opens. |

### Value

Position of the active item, as "2 / 5". Announced to screen readers when
it changes. Renders a `<span>` element.

**Value Props:**

| Prop     | Type                                                                   | Default                         | Description                                           |
| :------- | :--------------------------------------------------------------------- | :------------------------------ | :---------------------------------------------------- |
| children | `React.ReactNode \| ((state: Gallery.Value.State) => React.ReactNode)` | `` `${index + 1} / ${count}` `` | Content. A function receives the state, to format it. |

### List

Groups the triggers of a gallery and hides the ones past `limit` behind
`Gallery.More`. Place one `Gallery.Trigger` per item and a `Gallery.More`
inside it. Renders a `<div>` element.

**List Props:**

| Prop             | Type                            | Default | Description                                                                                                                                                                  |
| :--------------- | :------------------------------ | :------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| defaultExpanded  | `boolean`                       | `false` | Whether all the triggers are shown at first, when `expanded` is not controlled.                                                                                              |
| expanded         | `boolean`                       | -       | Whether all the triggers are shown, ignoring `limit`.                                                                                                                        |
| limit            | `number`                        | -       | Most places shown, `Gallery.More` included. Beyond it, the triggers after&#xA;`limit - 1` render nothing and `Gallery.More` shows the rest. Shows every&#xA;item when unset. |
| onExpandedChange | `((expanded: boolean) => void)` | -       | Called when `Gallery.More` shows all the triggers.                                                                                                                           |

### Portal

Moves the viewer to the end of `<body>` while it is open.
Renders a `<div>` element.

### Backdrop

Covers the page behind the viewer. While the image is dragged to close, it
gets `--gallery-dismiss-progress` (0 to 1), to fade it out:
`opacity: calc(1 - var(--gallery-dismiss-progress, 0))`. While the image
flies back, it has `data-ending-style` like any Base UI popup.
Renders a `<div>` element.

### Popup

The full-screen viewer. Place `Gallery.Viewport` and the controls inside.

Keys: ← → previous / next (pan while zoomed), ↑ ↓ pan, Home / End first /
last, + − zoom, 0 reset zoom, Esc close.

Has `data-zoomed` while the image is zoomed, `data-controls-hidden` after a
tap hides the controls, and `data-ending-style` while the image flies back
(fade the controls then, not the popup: the image is inside it). Gets
`--gallery-dismiss-progress` while the image is dragged to close.
Renders a `<div>` element.

### Item

One slide of the viewport, as large as the viewport. Its padding is the
space kept around the image (`p-6 md:p-24`, or `p-0` for edge to edge).
Renders a `<div>` element.

**Item Props:**

| Prop    | Type     | Default | Description                                                      |
| :------ | :------- | :------ | :--------------------------------------------------------------- |
| index\* | `number` | -       | Index of the item, as passed to the `Gallery.Viewport` children. |

### Title

Names the viewer for screen readers. Hide it visually if the design has no
visible title. Renders an `<h2>` element.

### Description

Caption of the active item, linked to the viewer for screen readers.
Shows `children`, or else the item's `caption`, and renders nothing when
there is neither. Renders a `<p>` element.

### Close

Closes the viewer; the image flies back to its trigger.
Renders a `<button>` element.

### Viewport

The swipeable strip of images. Handles the gestures: swipe, pinch, double
tap, pan, drag to close, wheel zoom. Give it a size (usually
`position: absolute; inset: 0` in the popup). Set the space between items with
`column-gap` (`gap-4`). Has `data-dragging` while a finger or the mouse
drags. Renders a `<div>` element.

**Viewport Props:**

| Prop       | Type                                                            | Default | Description                                                                                                               |
| :--------- | :-------------------------------------------------------------- | :------ | :------------------------------------------------------------------------------------------------------------------------ |
| children\* | `((item: Gallery.Item.Data, index: number) => React.ReactNode)` | -       | Renders one item: a `Gallery.Item` with a `Gallery.Image` inside. Called&#xA;only for the active item and its neighbours. |

### Image

The image of a `Gallery.Item`, fitted inside the item's padding. It is the
element that zooms, pans and flies. To use another image component, pass
it to `render` and spread the props: `render={(props) => <NextImage
{...props} fill sizes="100vw" />}`. Its position and size come from these
props, and its `transform` is set while it moves.
Renders an `<img>` element.

### Separator

Divides groups of actions. Inside `Gallery.Toolbar` it is a toolbar
separator, oriented across the toolbar. Renders a `<div>` element.

### Delete
