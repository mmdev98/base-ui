## API Reference

### Root

Groups the clipboard parts and holds the copied state.
Renders a `<div>` element.

**Root Props:**

| Prop           | Type                          | Default | Description                                                |
| :------------- | :---------------------------- | :------ | :--------------------------------------------------------- |
| value\*        | `string`                      | -       | The text written to the clipboard.                         |
| onCopiedChange | `((copied: boolean) => void)` | -       | Called when `copied` changes.                              |
| onCopyError    | `((error: unknown) => void)`  | -       | Called when the browser refuses to write to the clipboard. |
| timeout        | `number`                      | `2000`  | Time in milliseconds before `copied` goes back to `false`. |

### Trigger

A button that copies the value of `Clipboard.Root`.
Renders a `<button>` element.

### Indicator

Shows that the value was just copied, for example a check icon.
Renders a `<span>` element, only while `copied` is `true` unless `keepMounted` is set.

**Indicator Props:**

| Prop        | Type      | Default | Description                                                                                |
| :---------- | :-------- | :------ | :----------------------------------------------------------------------------------------- |
| keepMounted | `boolean` | `false` | Keep the element in the DOM when the value is not copied.&#xA;Style it with `data-copied`. |
