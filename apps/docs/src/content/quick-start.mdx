## Install

Install the package. React 19 is a peer dependency. Don't add `@base-ui/react` yourself:
this package brings the version it was built with.

```bash
pnpm add @mmdev98/base-ui
```

## Set up the portal root

Base UI's popups (dialogs, menus, the gallery viewer) are portaled to the end of `<body>`.
Give your app's root its own stacking context, so they always show on top of it:

```tsx title="app/layout.tsx"
<body>
  <div className="isolate">{children}</div>
</body>
```

## Style it

Parts render no styles of their own. Each one takes `className` and `style`, and exposes its
state as `data-*` attributes to style it with:

```tsx title="Style the copied state"
<Clipboard.Trigger className="text-neutral-500 data-copied:text-green-600">
  Copy
</Clipboard.Trigger>
```

Every page lists the data attributes and CSS variables of each part in its API reference.

## Change the element

The `render` prop replaces the element a part renders, or composes it with one of your
components. The part's props and behaviour are merged into it:

```tsx title="Compose your own button"
<Clipboard.Trigger render={<MyButton variant="ghost" />}>
  Copy
</Clipboard.Trigger>
```

## Use Base UI components

Every Base UI component is here too, under the same path as in `@base-ui/react`:

```tsx title="Import from one package"
import { Dialog } from "@mmdev98/base-ui/dialog";
import { Menu } from "@mmdev98/base-ui/menu";
import { useRender } from "@mmdev98/base-ui/use-render";
```

See [Base UI components](/docs/base-ui) for the full list.
