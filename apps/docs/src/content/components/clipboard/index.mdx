## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Clipboard } from "@mmdev98/base-ui/clipboard";

<Clipboard.Root>
  <Clipboard.Trigger>
    <Clipboard.Indicator />
  </Clipboard.Trigger>
</Clipboard.Root>;
```

## Examples

### Copied state

Every part has a `data-copied` attribute while the value was copied less than `timeout` milliseconds ago (2 seconds by default).
Style the parts with it, and listen to `onCopiedChange` to react in code.

```tsx title="Longer copied state"
<Clipboard.Root
  value={url}
  timeout={4000}
  onCopiedChange={(copied) => console.log(copied)}
>
  <Clipboard.Trigger>Copy link</Clipboard.Trigger>
</Clipboard.Root>
```

### Errors

Browsers can refuse to write to the clipboard, for example on an insecure origin or without a user gesture.
The copied state then stays off and `onCopyError` receives the error.

```tsx title="Report a refused copy"
<Clipboard.Root value={token} onCopyError={() => toast.error("Copy failed")}>
  <Clipboard.Trigger>Copy token</Clipboard.Trigger>
</Clipboard.Root>
```

### Indicator

`Clipboard.Indicator` renders only while copied. Set `keepMounted` to keep it in the DOM and animate it with `data-copied`.

```tsx title="Fade the check in"
<Clipboard.Root value={url}>
  <Clipboard.Trigger className="group relative size-8">
    <CopyIcon className="group-data-copied:invisible" />
    <Clipboard.Indicator
      keepMounted
      className="absolute inset-0 flex items-center justify-center text-green-600 opacity-0 transition-opacity duration-200 data-copied:opacity-100"
    >
      <CheckIcon />
    </Clipboard.Indicator>
  </Clipboard.Trigger>
</Clipboard.Root>
```

### Styling

Every part has `data-copied` while copied, so Tailwind's `data-copied:` variant styles it, and `group-data-copied:` styles what's inside a part.
