## Usage guidelines

- **The images fly:** the image grows out of its thumbnail when the viewer opens and flies back when it closes. Hide the thumbnail while it has `data-flying`.
- **One gesture engine:** swipe, pinch, double tap, pan and drag to close are handled together, so they never fight over a touch. The viewer needs no carousel or zoom library.
- **No dependencies:** the gallery needs no carousel, zoom, animation or image library, and no framework. `Gallery.Image` renders a plain `<img>`; give it any `src` or `srcSet`, or another element through `render`.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Gallery } from "@mmdev98/base-ui/gallery";

<Gallery.Root>
  <Gallery.List>
    <Gallery.Trigger />
    <Gallery.More />
  </Gallery.List>
  <Gallery.Portal>
    <Gallery.Backdrop />
    <Gallery.Popup>
      <Gallery.Title />
      <Gallery.Viewport>
        {(item, index) => (
          <Gallery.Item index={index}>
            <Gallery.Image />
          </Gallery.Item>
        )}
      </Gallery.Viewport>
      <Gallery.Description />
      <Gallery.Close />
      <Gallery.Toolbar>
        <Gallery.Previous />
        <Gallery.Value />
        <Gallery.Next />
        <Gallery.Separator />
        <Gallery.ZoomOut />
        <Gallery.ZoomValue />
        <Gallery.ZoomIn />
        <Gallery.ZoomReset />
      </Gallery.Toolbar>
    </Gallery.Popup>
  </Gallery.Portal>
</Gallery.Root>;
```

## Examples

### Items

`Gallery.Root` takes the images as `items`. Each item needs a stable `id` and a `src`. Its `width` and `height` give the viewer the right shape before the image has loaded, and its `caption` is what `Gallery.Description` shows.

```tsx title="Items"
const items = [
  {
    id: "1",
    src: "/photos/1.jpg",
    width: 1600,
    height: 1067,
    alt: "Valley",
    caption: "Valley",
  },
  { id: "2", src: "/photos/2.jpg", alt: "Portrait" },
];

<Gallery.Root items={items}>…</Gallery.Root>;
```

#### Resized images

Show smaller images as thumbnails and larger ones in the viewer by giving `Gallery.Image` its own `src` or `srcSet`: your props win over the item's. Pass `loadImage` to `Gallery.Root` so the viewer preloads the same URL before it opens.

```tsx title="Resized images"
import {
  Gallery,
  loadGalleryImage,
  type GalleryItemData,
} from "@mmdev98/base-ui/gallery";

// Any image service that resizes from the URL.
const getViewerSrc = (item: GalleryItemData) => `${item.src}?width=2000`;

<Gallery.Root
  items={items}
  loadImage={(item) => loadGalleryImage({ ...item, src: getViewerSrc(item) })}
>
  {items.map((item, index) => (
    <Gallery.Trigger key={item.id} index={index}>
      <img src={`${item.src}?width=200`} alt="" />
    </Gallery.Trigger>
  ))}
  <Gallery.Portal>
    <Gallery.Popup>
      <Gallery.Viewport>
        {(item, index) => (
          <Gallery.Item index={index}>
            <Gallery.Image
              src={getViewerSrc(item)}
              srcSet={`${item.src}?width=1000 1000w, ${getViewerSrc(item)} 2000w`}
              sizes="100vw"
            />
          </Gallery.Item>
        )}
      </Gallery.Viewport>
    </Gallery.Popup>
  </Gallery.Portal>
</Gallery.Root>;
```

### Mobile gestures

The viewer works like the photo app of a phone:

- **Swipe** between images; the image follows the finger, carries on with the flick, and rubber-bands at the first and last image.
- **Pinch** to zoom around the fingers, and **double tap** to zoom in at the tapped point or back out.
- **Pan** a zoomed image; past its edge, the drag carries on to the next image.
- **Drag down** (or up) to close: the image follows the finger, the backdrop fades, and it flies back on release.
- **Tap** to hide or show the controls.

With a mouse or trackpad, drag swipes, double click zooms, and the wheel or a trackpad pinch zooms around the cursor.

#### Edge to edge

Like a phone's photo app: no padding around the image, translucent bars, and a tap hides them. Try it on a phone or with the browser's device toolbar.

### Styling

Every part is unstyled. Style the viewer with Tailwind (or any CSS), using the parts' data attributes and CSS variables:

- `Gallery.Popup` has `data-zoomed` while the image is zoomed, `data-controls-hidden` after a tap hid the controls, and `data-starting-style` / `data-ending-style` while the image flies in and out. Fade the controls, not the popup: the image is inside it. From a control, read them with `in-data-*`: `in-data-controls-hidden:opacity-0`.
- `Gallery.Popup` and `Gallery.Backdrop` get `--gallery-dismiss-progress` (0 to 1) while the image is dragged to close: `opacity-[calc(1_-_var(--gallery-dismiss-progress,0))]`.
- `Gallery.Popup` and `Gallery.Backdrop` have `data-dragging` during a drag, and until the image settles back after a drag to close. Turn transitions off then (`data-dragging:transition-none`, or `in-data-dragging:transition-none` on a control), or whatever follows `--gallery-dismiss-progress` lags behind the finger.
- `Gallery.Viewport` has `data-dragging` during a gesture. Give it a size (`absolute inset-0`) and set the space between images with `gap-x-4`.
- `Gallery.Item`'s padding is the space around the image: `p-0` for edge to edge on phones, `md:px-24 md:py-18` on larger screens. Add `pt-[env(safe-area-inset-top)]` and the like for notches.
- `Gallery.Trigger` has `data-popup-open` while the viewer shows its image, from the opening flight to the end of the closing one. Hide it with `data-popup-open:invisible`: the thumbnail disappears from the list but keeps its place, as in a phone's photo app, and comes back when the image flies home. It also has `data-pending` while its image loads (`data-pending:opacity-60`) and `data-flying` while it flies.

```tsx title="Styling the viewer"
<Gallery.Backdrop className="fixed inset-0 bg-black opacity-[calc(1_-_var(--gallery-dismiss-progress,0))] transition-opacity duration-300 data-dragging:transition-none data-starting-style:opacity-0 data-ending-style:opacity-0" />
<Gallery.Popup className="fixed inset-0 text-white outline-none">
  <Gallery.Viewport className="absolute inset-0 gap-x-4 cursor-zoom-in in-data-zoomed:cursor-grab data-dragging:cursor-grabbing">
    {(item, index) => (
      <Gallery.Item index={index} className="p-0 md:px-24 md:py-18">
        <Gallery.Image />
      </Gallery.Item>
    )}
  </Gallery.Viewport>
  <Gallery.Close className="absolute top-3 right-3 transition-opacity duration-200 in-data-dragging:transition-none in-data-controls-hidden:opacity-0 in-data-ending-style:opacity-0">
    ✕
  </Gallery.Close>
</Gallery.Popup>
```

### Keyboard

| Key        | Action                                       |
| :--------- | :------------------------------------------- |
| ← →        | Previous / next image, or pan while zoomed   |
| ↑ ↓        | Pan while zoomed                             |
| Home / End | First / last image                           |
| + −        | Zoom in / out                                |
| 0          | Reset the zoom                               |
| Esc        | Close; the image flies back to its thumbnail |

Inside `Gallery.Toolbar`, the arrow keys move between the actions, and disabled actions stay focusable.
