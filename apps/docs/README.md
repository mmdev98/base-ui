# Docs

The documentation of `@mmdev98/base-ui-plus`: every re-exported Base UI component and the components
this repo adds. Copied from [Base UI](https://github.com/mui/base-ui)'s docs at `v1.8.0` (MIT) and
adapted.

Start it from the project root:

```bash
pnpm dev
```

It runs at http://localhost:3005 and reads the library from source, so changes show up without a
build. See the _Docs_ section of the root `AGENTS.md` for how pages, demos and API tables work.

`src/error-codes.json` lists Base UI's minified production errors, which the error page decodes.
